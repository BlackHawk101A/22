Task: Implement split_list(+List, -Left, -Right) in SWI-Prolog for P2.

Requirements:
- Split List into two non-empty contiguous sublists Left and Right, keeping the original order.
- Should generate all valid splits on backtracking.
- Must fail cleanly (no errors, no loops) if List has 0 or 1 elements.
- Pure Prolog only (no assert/retract, no global vars, no printing).
- Add a brief declarative comment above the predicate.


Task: Implement build_expr(+Nums, -Tree, -Value) in SWI-Prolog for P2.

Requirements:
- Base case: a single-element list [N] produces num(N) with Value = N.
- Recursive case: use split_list/3 to split Nums into LeftNums and RightNums, recursively build left and right sub-expressions, and combine them into op(Op, LeftTree, RightTree) for Op in +, -, *, /.
- Division (/) is only valid when RightVal =\= 0 and LeftVal mod RightVal =:= 0 (exact integer division using //).
- Sub-expression values may be negative. No unary minus, no digit concatenation, and no string parsing to evaluate.
- Pure Prolog only, with a brief declarative comment above the predicate.


Task: Implement expr_to_string(+Tree, -Str) in SWI-Prolog for P2.

Requirements:
- Convert an expression tree (num(N) or op(Op, Left, Right)) into a canonical SWI-Prolog string (double-quoted string, not an atom) with no spaces.
- Precedence rules: * and / bind tighter than + and -.
- Parenthesization rules:
  - A single number is never in parentheses.
  - A left operand is parenthesized only if its top operator has strictly lower precedence than its parent's operator.
  - A right operand is parenthesized if its top operator has the same or lower precedence than its parent's operator.
- Pure Prolog only, with brief declarative comments above predicates.

Task: Implement generate_equation(+List, -Equation) in SWI-Prolog for P2.

Requirements:
- Use split_list/3 to split List into LeftNums and RightNums.
- Use build_expr/3 on both sides and ensure both evaluate to the same integer Value.
- Use expr_to_string/2 on both trees and combine them into an SWI-Prolog string "LeftStr=RightStr" with no spaces.
- Must fail cleanly (no errors, no loops) if no valid equation exists, including for lists of length 0 or 1.
- Pure Prolog only, no printing, with a brief declarative comment above the predicate.

Task: Implement all_equations(+List, -Equations) and count_equations(+List, -N) in SWI-Prolog for P2.

Requirements:
- all_equations(List, Equations) collects all valid equations from generate_equation/2, removes duplicates, and sorts them using sort/2 (standard order of terms). If no valid equations exist, Equations = [].
- count_equations(List, N) unifies N with the length of Equations from all_equations/2.
- Pure Prolog only, no printing, with brief declarative comments above both predicates.
