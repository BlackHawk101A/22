### Prompt 1 - Accessors and inorder traversal (S1.a)

Task: For S1 in `code/22_q3.rkt`, write accessors `node-value`, `node-left`, `node-right` for a tree `(value left right)`, then `(inorder-acc tree acc)` and `(print-inorder tree)`.

Requirements:
- No `append` or `reverse`. I want to build the inorder list with an accumulator by visiting the right subtree first, so values get consed on in the correct order. Explain why visiting right-then-node-then-left with `cons` gives left-node-right order.
- The empty tree `()` gives `()`.
- `print-inorder` uses `display` then `newline`.
- Add a comment above each function with its signature and recursive reading, and say whether it's tail-recursive and why or why not.

### Prompt 2 - Preorder, postorder and print-all-traversals (S1.b)

Task: Using the same accumulator idea as `inorder-acc`, write `(preorder-acc tree acc)`, `(postorder-acc tree acc)` and `(print-all-traversals tree)` in `code/22_q3.rkt`.

Requirements:
- Still no `append` or `reverse`. For each traversal, tell me in which order the node and the two subtrees have to be added to the accumulator, and why that is the reverse of the order they appear in the output.
- `print-all-traversals` prints three lines: inorder, preorder, postorder, each with `display` then `newline`.
- Reuse `inorder-acc` and the accessors from before instead of rewriting them.
- Same comment style as before (signature, recursive reading, tail-recursive or not).

### Prompt 3 - Height, leaf count and print-height-and-leaves (S1.c)

Task: Write `(height tree)`, a predicate `(leaf? tree)`, `(leaf-count tree)` and `(print-height-and-leaves tree)` in `code/22_q3.rkt`.

Requirements:
- Height of `()` is 0 and a node is 1 + max of its subtrees, so a single node is height 1. Check this against t2 = `(1 () (2 () (3 () ())))`, which should give height 3 and 1 leaf.
- A leaf is a node with both children `()`. Make sure `()` itself is not counted as a leaf - explain what would go wrong for `(print-height-and-leaves '())` if it were.
- Use only `max`, `+` and the allowed list primitives.
- Print `(height leaf-count)` with `display` then `newline`.
- Same comment style (signature, recursive reading, tail-recursive or not).
