# Prompts for Problem P1

### Prompt 1 - Creating the main program file (Task P1.a + c)

Write a Prolog program for the following problem, and save it in a file called id_q1.pl

Four friends (Alex, Ben, Carla, Dana) each have a department, a favorite language and a project preference.
• Department: research, development, design, testing
• Favorite language: python, java, c++, javascript
• Project: AI, web, embedded, data
Every friend has a different value for each attribute, so each of the four values of each attribute is used exactly once.
Clues (numbered; the numbers are used by the tests)
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.

Also add a 9th clue yourself, that reduces number of possible solutions to 1.

A solution is a Prolog list of four terms p(Name, Dept, Lang, Project), in the order Alex, Ben, Carla, Dana. The names are the quoted atoms 'Alex', 'Ben', 'Carla', 'Dana'. The values are exactly these atoms: research, development, design, testing; python, java, 'c++', javascript; 'AI', web, embedded, data. Format example only (this is not the answer):
[p('Alex',design,java,web), p('Ben',testing,python,data), ...]

Write each clue as its own clause clue(N, Solution) that succeeds exactly when clue number N holds in a fully filled-in Solution.

Constraints: no assert, retract or global variables (b_setval, nb_setval). Allowed libraries: lists, apply, yall, aggregate. Do not print anything other than what is specified.


### Prompt 2 - Adding a function to count number of possible solutions (Task P1.b)

Add a function called count_solutions(Active, N), according to the following specification.

Define count_solutions(Active, N). Active is a list of clue numbers (for example
[1,2,3,4,5,6,7,8]). N is the number of solutions that satisfy exactly the clues in Active and ignore all the others. Use findall/3 (or aggregate_all/3). Report in P1_REPORT.md the value of N for clues 1 to 8, and say what it tells you about the puzzle.
